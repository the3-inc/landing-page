# トップページの内容・導線の参考調査

確認日: 2026-10-19。対象は各社の公式トップページ。以下の「観察」は公開ページの構成、「提案」はthe3への設計判断を示す。画面の高さや余白の寸法は、この調査では検証していない。

## 公式サイトで確認した構成

| 参考サイト | 観察した構成 | the3に取り入れたい点 |
| --- | --- | --- |
| [LayerX](https://layerx.co.jp/) | 冒頭のメッセージに続けて使命を説明し、事業ごとの短い紹介から詳細へ案内する。ニュース、採用、お問い合わせも別の目的として配置している。 | 理念だけで終わらせず、「何に取り組む会社か」と具体的な製品を続ける。 |
| [Goodpatch](https://goodpatch.com/ja) | 会社の役割を説明し、事業・支援内容とその詳細、制作実績、自社サービスを紹介する。会社の理念と、相談できる内容を添えた問い合わせ導線もある。 | 抽象的な価値を、向き合う課題・取り組み方・相談内容に言い換える。 |
| [ユーザベース](https://www.uzabase.com/jp/) | 使命と目指す姿を冒頭に置く。サービスは短い説明と詳細へのリンクで紹介し、会社情報・採用・お問い合わせを目的別の導線として用意している。 | トップは全体像をつかむ入口とし、製品の詳しい条件や会社情報は既存ページへつなぐ。 |

## the3への提案

トップを「理念 → 理念の意味 → 取り組み方 → 製品 → 会社案内 → 相談」の順にする。文字数や空白を埋めるために増やすのではなく、読者の「何を大切にする会社か」「何ができるか」「次にどこへ進むか」に答える。

- **理念**: 既存の「社会に一つでも多く価値あるものを提供する。」を主題として保つ。「価値」を、繰り返す作業や複雑な調整の負担を減らし、人が考え、工夫する時間をつくることとして説明する。
- **取り組み方**: 業務を知る、仕組みにする、使いながら改善する、という姿勢を短く示す。支援実績や成果の保証として表現しない。
- **具体例**: 既存のshift-schedulaを、理念が製品になる例として紹介する。技能・勤務可能時間・必要人数・勤務ルールという具体的な条件を用いる。
- **相談**: 業務の課題整理や製品の導入・個別開発など、何を相談できるかを書いてから問い合わせ先へ案内する。

## 既存ページの役割

| ページ | 読者が確認すること | トップからの導線 |
| --- | --- | --- |
| `/` | 理念、取り組み方、提供するものの全体像 | ページ内の各紹介へスクロール |
| `/company/` | 会社情報・事業内容・所在地 | 「会社案内を見る」 |
| `/products/` | 製品の一覧と導入・開発の相談先 | 「製品・導入支援を見る」 |
| `/products/schedula/` | 製品の条件・用途、デモ・技術案内、導入支援の範囲 | 「shift-schedulaについて」 |
| `/contact/` | 相談できる内容と連絡方法 | 「お問い合わせ」 |

各社にあるニュース、採用、顧客ロゴ、事例、導入効果の数字、認証表示は、the3の公開根拠が揃うまで追加しない。参考にするのは情報の組み立て方であり、他社の文章・実績・事業規模は転用しない。現在の根拠は`src/pages/company.astro`、`src/pages/products/index.astro`、`src/pages/products/schedula.astro`にある会社・製品情報。
