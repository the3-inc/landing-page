# the3 共通デザインプリセット

色・本文書体・余白・ライト／ダークテーマ・フォーカス表示・主要ボタンの正本です。
Astro・Tailwind・Reactなどに依存しないCSSとして配布できます。
会社と製品の画面を担当する人が、同じ値を別々に管理せずに利用するためのパッケージです。

## 現在の利用

会社サイトの `src/styles/global.css` から `base.css` を直接読み込んでいます。
同ファイルの `@theme` はプリセットの値を既存のTailwind名へ対応付けるだけです。
会社のヘッダー・ページ幅・本文レイアウトは会社サイト、製品固有の構成は製品側が所有します。
この版を取り込むために製品側のフレームワークを変える必要はありません。

このディレクトリは配布可能なソースですが、現時点ではレジストリ未公開です。
`private: true` により誤った公開を防止しています。他リポジトリへの導入は未実施です。

## 他リポジトリへの取り込み

手作業でCSSをコピーする運用にはせず、版を固定したパッケージをビルドに取り込みます。
現時点では、このディレクトリで `npm pack` を実行すると `the3-brand-preset-0.1.0.tgz` を作れます。
そのアーカイブを利用側のパッケージ管理で依存関係に追加すれば、以下の読み込み方が使えます。
パッケージ管理を使わない製品は、同じ版のアーカイブをビルド時に展開し、CSSを自身の成果物へ含めます。

```css
/* 基本スタイルとトークン。会社サイトや新しい製品の既定。 */
@import "@the3/brand-preset/base.css";
```

既存アプリの背景や本文スタイルを維持する場合は、値だけを利用します。

```css
@import "@the3/brand-preset/tokens.css";

.product-title {
  color: var(--the3-accent);
  font-family: var(--the3-font-sans);
}
```

CSSのimportはビルドツールによる解決を前提とします。ブラウザーへパッケージ名をそのまま渡しません。
プレーンHTMLでは、展開した `base.css` と `tokens.css` を同じディレクトリに配信し、`link` 要素で読み込めます。
`base.css` の全体スタイルは本文の色・背景・書体・余白リセット、選択色、フォーカス、スクロール設定です。
ボタンは `class="the3-button"` で使えます。本文の文字サイズや見出し、メニュー構成は利用側で決めます。

## テーマと製品の個性

既定はOSのテーマへ追従します。明示する場合は `html` の `data-theme="light"` / `"dark"` を使います。
テーマ切り替えUIや保存処理は含みません。HTMLの言語、viewport、本文へ移動するリンク、会社・製品への導線は各画面で用意します。
フォーカス表示は文字色から独立し、塗りボタンにも表示されます。動きを減らす設定ではスムーズスクロールを無効にします。

製品固有の図解・画面密度・構成は製品側に置きます。アクセントを変更する場合は、ライトとダークの双方で
`--the3-accent` と `--the3-on-accent` を組にして上書きし、本文・ボタン・フォーカスのコントラストを確認します。
会社ロゴの正本と使用方針は `docs/brand-assets.md` にあり、このパッケージへ会社ナビゲーションは含めません。

## 継続的な配布

複数リポジトリで採用するときは、この小さなパッケージを会社共通の管理先へ移し、
利用するリポジトリから取得できるレジストリで版を付けて配布する方針です。
管理先と公開先の決定、レジストリ設定はまだ行っていません。

利用側は版とlockfileを固定し、更新PRで取り込みます。共通側を更新しただけでは公開済みサイトは変わりません。
更新PRでは各製品のビルド、狭い画面、両テーマ、キーボード操作、往復リンクを確認してから各サイトを公開します。
問題があれば依存バージョンとlockfileを戻し、再ビルド・再公開します。
稼働中の会社サイトから「最新CSS」を読み込む方式や、テンプレートの再コピーによる更新は使いません。

色や基本部品の変更はここで行い、利用側で同じ値を再定義しません。
製品の機能やデータ構造、各画面のレイアウト、認証、計測、公開処理を共通パッケージへ集めないことが境界です。
